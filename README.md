# Desk Slugger

바탕화면 위에서 돌아가는 투명 오버레이 방식의 Desktop Mate 야구 게임입니다. 일반 웹페이지가 아니라 Electron 기반 Windows 데스크톱 앱이며, 모니터 맨 아래를 지면으로 사용하는 2D 횡스크롤 시점으로 표시됩니다.

## 실행

```powershell
npm.cmd install
Copy-Item ranking-config.example.json ranking-config.json
npm.cmd start
```

`ranking-config.json`의 서버 주소와 리그 키는 사용할 내부망 환경에 맞게 수정합니다.
이 파일은 공개 저장소에 커밋되지 않습니다.

## Windows 실행 파일 만들기

```powershell
npm.cmd run dist
```

완성된 포터블 실행 파일은 `dist/Desk-Slugger-{version}.exe`에 생성되며,
동시에 `updates/Desk-Slugger-latest.exe`와 업데이트 manifest가 갱신됩니다.

트레이의 `업데이트`를 누르면 내부망 서버의 최신 버전을 확인하고 다운로드·검증한 뒤
현재 EXE를 교체하고 자동으로 재실행합니다. 자동 업데이트 기능이 없는 구버전은
`0.7.25` 이상을 한 번 직접 전달해야 합니다.

## 내부망 랭킹 서버

내부망 PC 한 대를 공동 랭킹·업데이트 서버로 사용합니다.

```powershell
Copy-Item .env.example .env
docker compose up -d --build
```

`.env`와 `ranking-config.json`에는 동일한 충분히 긴 `LEAGUE_KEY`를 설정합니다.

- API: `http://<서버-PC-IP>:47831`
- DB: `ranking-data/desk-slugger.db`
- Stop: `docker compose down`
- Logs: `docker compose logs -f ranking-server`
- The container restarts automatically with Docker Desktop, and the SQLite DB
  remains in the host `ranking-data` directory.
- 공유기 포트포워딩은 사용하지 않습니다.
- 서버 PC가 켜져 있고 랭킹 서버가 실행 중이어야 저장됩니다.
- 공유기의 DHCP 예약으로 서버 PC 주소를 고정하는 것을 권장합니다.
- 게임 종료 시 서버가 예상 순위를 먼저 계산합니다.
- TOP 10 점수일 때만 닉네임 입력란이 표시되며 등록 순간 서버가 순위를 다시 검증합니다.
- 11위 이하 점수는 DB에 저장하지 않고 `랭킹 등록 실패 · N위`로 실제 예상 순위를 표시합니다.
- 등록 성공 후에는 1~10위 목록을 표시하고 방금 등록한 본인 기록을 강조합니다. TOP 10 미진입 시에는 입력 없이 목록을 바로 표시합니다.
- 닉네임은 한글·영문·숫자·공백·밑줄·하이픈으로 1~12자까지 사용할 수 있습니다.

## 플레이

- 앱을 켜면 투수가 자동으로 공을 던집니다.
- 물리 모니터 중앙이 배트 조작의 중립점입니다. 마우스를 왼쪽에서 오른쪽으로 움직이면 스윙하고, 좌하단에서 우상단으로 움직이면 어퍼스윙이 됩니다.
- 스윙은 투구 하나당 한 번만 유효하며, 마우스 속도·진행 방향·스위트 스폿 접촉 위치로 타구 방향과 비거리가 결정됩니다.
- 빠르게 지나간 배트는 최근 0.075초의 짧은 궤적으로 충돌을 검사하며, 판정 위치와 화면에 그려지는 배트 위치가 같은 프레임을 사용합니다.
- 평소 마우스 클릭은 투명 오버레이를 그대로 통과하므로 다른 앱과 바탕화면을 계속 사용할 수 있습니다.
- 타자·포수·투수가 작업표시줄 바로 위의 같은 지면선에 서며, 내·외야수는 표시하지 않습니다.
- 타자가 치지 못한 공은 포수가 받고 투수에게 되던집니다. 투수는 같은 공을 글러브에서 투구 손으로 옮긴 뒤 다음 투구를 시작합니다.
- 투구와 타구는 옆에서 보는 2D 포물선으로 움직입니다.
- 캐릭터는 검은색 관절형 졸라맨이며 `motion.js`의 키프레임 클립으로 움직입니다.
- 관절 리그와 동작 데이터가 게임 판정 코드에서 분리되어 있어 세부 모션을 독립적으로 추가·수정할 수 있습니다.
- 배트는 내부적으로 yaw·pitch·depth를 가진 3D 벡터로 움직이고 원근 투영되지만, 가독성을 위해 최종 실루엣은 항상 캐릭터 앞에 표시됩니다.
- 물리와 입력은 모니터 주사율에 맞춰 부드럽게 계산하고, 키 포즈는 12 FPS 애니메이션 타이밍을 기준으로 작성하며 동작별 timing/spacing과 smear frame을 사용합니다.
- 마우스 위치는 타자 주변의 가상 3D 트랙볼에 매핑되고, 배트는 스프링 관성으로 이를 추적합니다. 타격 강도는 실제 배트 끝 속도로 계산됩니다.
- 좌우 어깨·골반이 분리된 고정 길이 골격과 안정화된 2-bone IK가 팔꿈치·무릎을 계산해 동작 중 팔다리가 늘어나거나 관절이 갑자기 뒤집히지 않습니다.
- 게임 화면에는 별도 UI, 점수판, 안내 문구, 배경, 지면선 없이 캐릭터와 공·배트만 표시됩니다.
- 시스템이 라이트 모드면 검은 졸라맨, 다크 모드면 흰 졸라맨으로 자동 전환됩니다. 원근상 뒤쪽 팔다리와 배럴은 낮은 명도로, 앞쪽은 높은 대비로 표시됩니다.
- 10,000점부터는 구속·변화·흔들림과 소멸/분신 여부가 매번 달라지는 하이퍼스피드 랜덤 구만 투구됩니다.
- 개인 최고 점수에 따라 아이언→브론즈→실버→골드→플래티넘→에메랄드→다이아→마스터→그랜드마스터→챌린저 배트가 적용됩니다. 등급별 외형과 궤적 색상이 달라지고 정타·파워 보정은 최대 약 5%로 제한됩니다.
- 타격은 강도 6단계와 타구 궤적 8종을 조합해 48가지 기본 결과로 분류하며, 실제 속도·발사각·백스핀은 연속 값으로 계산됩니다.
- 오른쪽 경계 통과 높이에 따라 200·300·500·700·1,000·1,200·1,500점이 지급되고, 7단계별 경계 효과와 보조 파티클이 적용됩니다.
- 안타와 타구 높이에 따라 점수가 누적되고 삼진 3회면 최종 점수 화면이 나타납니다. TOP 10 기록은 내부망 랭킹 DB에 닉네임과 함께 저장됩니다.

## 트레이 메뉴

작업표시줄 알림 영역의 야구공 아이콘을 클릭하면 캐릭터를 숨길 수 있습니다.
우클릭 메뉴에서 랭킹, 버전·업데이트 내역, 자동 업데이트, 임시 이펙트 미리보기, 종료 기능을 사용할 수 있습니다.
