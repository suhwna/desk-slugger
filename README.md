# Desk Slugger

바탕화면이 그대로 야구장이 되는 마우스 타격 게임입니다.

별도의 경기장 배경 없이 모니터 아래쪽을 지면으로 사용하며, 투수·타자·포수가 바탕화면 위에서 경기를 진행합니다. 투수는 자동으로 공을 던지고, 플레이어는 마우스를 움직여 배트를 휘두릅니다. 마우스 클릭은 필요하지 않습니다.

## 플레이 방법

1. 마우스를 **모니터 중앙** 근처에 두면 타자가 기본 타격 자세를 잡습니다.
2. 공이 날아오기 전에 마우스를 왼쪽으로 옮겨 백스윙을 준비합니다.
3. 공이 타자 앞에 도착할 때 마우스를 **왼쪽에서 오른쪽으로 빠르게** 움직여 타격합니다.
4. 배트의 굵은 부분에 공을 정확히 맞히면 더 빠르고 멀리 날아갑니다.

투구 하나에는 한 번의 스윙만 유효합니다. 작은 손목 움직임보다 방향이 분명한 한 번의 스윙이 안정적입니다.

### 스윙 방향

| 마우스 움직임 | 타구 성향 |
| --- | --- |
| 왼쪽 → 오른쪽 | 기본 스윙, 라인드라이브 |
| 좌하단 → 우상단 | 어퍼스윙, 높은 장타 |
| 좌상단 → 우하단 | 다운스윙, 낮은 타구와 땅볼 |
| 빠르고 크게 이동 | 배트 끝 속도와 타구 파워 증가 |

마우스의 방향은 배트 각도에, 이동 속도는 배트 끝 속도에 반영됩니다. 빠른 공을 배트 진행 방향의 정면에서 받아치면 투구의 힘까지 실려 조금 더 강한 타구가 나옵니다.

## 좋은 타구를 만드는 요령

- 투구 전에는 마우스를 모니터 중앙으로 돌려 타격 자세를 정리합니다.
- 공이 오기 전에 왼쪽으로 이동해 충분한 백스윙 공간을 만듭니다.
- 공을 띄우고 싶다면 좌하단에서 우상단으로 부드럽고 빠르게 통과합니다.
- 너무 일찍 휘두르면 배트가 공보다 먼저 지나가고, 너무 늦으면 손잡이 쪽에 맞기 쉽습니다.
- 무조건 큰 어퍼스윙을 하기보다 공의 높이에 맞춰 스윙 각도를 조절하는 편이 좋습니다.
- 정타 순간에는 짧은 화면 정지와 강한 충격 효과가 발생합니다.

타격 결과는 배트 속도, 스윙 방향, 공과 배트의 충돌 각도, 스위트 스폿 정확도, 타이밍을 함께 계산합니다. 같은 방향으로 휘둘러도 맞은 위치에 따라 땅볼·라인드라이브·뜬공·문샷으로 달라질 수 있습니다.

## 게임 규칙

- 투수는 자동으로 다음 공을 준비해 던집니다.
- 공을 놓치면 스트라이크가 추가되고 포수가 공을 받아 투수에게 돌려줍니다.
- 스트라이크 3개가 되면 경기가 종료됩니다.
- 친 공이 투수의 글러브에 잡혀도 아웃으로 경기가 종료됩니다.
- 아웃되기 전까지 친 타구의 점수가 계속 누적됩니다.
- 게임 종료 후 최종 점수, 개인 최고 점수, 현재 배트 등급과 공동 랭킹을 확인할 수 있습니다.

## 점수

화면 안에서 떨어진 타구는 거리와 최고 높이에 따라 점수를 받습니다.

| 타구 결과 | 점수 |
| --- | ---: |
| 땅볼 또는 짧은 타구 | 100 |
| 깊은 타구 | 200 |
| 낮은 뜬공 | 300 |
| 높은 뜬공 | 500 |
| 화면 안의 초대형 타구 | 1,000 |

공이 모니터 오른쪽 경계를 넘어가면, 넘어간 높이가 높을수록 더 큰 점수와 전용 연출이 발생합니다.

| 경계 타구 등급 | 점수 |
| --- | ---: |
| LOW EXIT | 200 |
| LOW DRIVE | 300 |
| RISING DRIVE | 500 |
| HIGH DRIVE | 700 |
| SKY SHOT | 1,000 |
| UPPER DECK | 1,200 |
| ZENITH | 1,500 |
| ASCENSION | 2,000 |
| BEYOND | 3,000 |

`ASCENSION`과 `BEYOND`에는 각각 전용 시네마틱 효과가 적용됩니다. 높은 등급일수록 경계 폭발과 파티클도 더 강하게 표현됩니다.

## 타격 등급과 행운의 타격

타격은 강도 6단계와 타구 궤적 8종의 조합으로 세분화되어 있습니다. 화면에는 복잡한 판정 문구를 띄우지 않고, 타구의 속도·높이·궤적과 충격 효과로 결과를 보여줍니다.

유효 타격에는 **1% 확률로 행운의 타격**이 발생합니다. 발동하면 기존 접촉 품질과 관계없이 최강 파워와 장타에 유리한 각도가 적용되며, 녹색과 금색의 전용 효과가 나타납니다. 점수 자체를 곱하지는 않으며 실제로 공이 날아간 결과에 따라 점수를 받습니다.

## 투수 난이도

점수를 쌓을수록 투수가 점점 강한 공을 던집니다. 난이도는 화면 점수와 별도로 서서히 누적되기 때문에 한 번의 고득점 타구만으로 여러 단계를 건너뛰지는 않습니다.

| 난이도 점수 | 등장하는 공 |
| --- | --- |
| 0 이상 | 느린 직구 |
| 500 이상 | 일반 직구 |
| 1,000 이상 | 직구와 변화구 |
| 2,000 이상 | 빠른 직구와 빠른 변화구 |
| 3,000 이상 | 빠른 공과 마구·소멸구·일루전구 |
| 4,000 이상 | 초고속 공과 강화된 마구 |
| 5,000 이상 | 초고속 마구 중심 |
| 10,000 이상 | 무작위 하이퍼스피드 랜덤 구 |

소멸구는 비행 중 잠깐 보이지 않으며, 일루전구는 순간적으로 여러 공이 날아오는 것처럼 보입니다. 실제 판정 대상은 하나입니다.

## 배트 등급

개인 최고 점수가 올라가면 다음 배트가 해금됩니다. 한 경기를 시작할 때 사용 배트가 고정되며, 경기 도중 최고 점수를 갱신해도 바로 바뀌지 않습니다. 새 배트는 최종 결과 화면에서 해금 안내가 나온 뒤 **다음 경기부터** 적용됩니다.

| 개인 최고 점수 | 배트 |
| ---: | --- |
| 0 | 아이언 |
| 2,000 | 브론즈 |
| 5,000 | 실버 |
| 9,000 | 골드 |
| 14,000 | 플래티넘 |
| 20,000 | 에메랄드 |
| 28,000 | 다이아몬드 |
| 38,000 | 마스터 |
| 50,000 | 그랜드마스터 |
| 65,000 | 챌린저 |

등급이 높은 배트는 외형과 궤적이 달라지며, 정타 허용 범위와 파워가 조금씩 좋아집니다. 실력의 영향이 가장 크고 배트 성능은 보조적인 차이만 제공합니다.

## 랭킹과 개인 최고 점수

- 경기 결과가 공동 랭킹 TOP 10 안에 들면 닉네임 입력란이 표시됩니다.
- 닉네임은 한글·영문·숫자·공백·밑줄·하이픈을 사용해 1~12자로 입력할 수 있습니다.
- 등록 후 1~10위 목록에서 자신의 기록이 강조됩니다.
- TOP 10에 들지 못하면 예상 순위를 알려주고 현재 랭킹 목록을 바로 보여줍니다.
- 결과 화면과 랭킹 화면에서 자신의 개인 최고 점수를 확인할 수 있습니다.
- 랭킹 서버에 연결되지 않아도 게임과 로컬 최고 점수 기록은 계속 이용할 수 있습니다.

## 화면과 트레이 메뉴

게임 중에는 별도의 경기장 배경이나 상시 점수판 없이 캐릭터, 공, 배트와 필요한 효과만 바탕화면 위에 나타납니다. 시스템이 다크 모드라면 캐릭터가 밝게, 라이트 모드라면 어둡게 표시됩니다.

작업표시줄 알림 영역의 야구공 아이콘을 클릭하면 캐릭터를 숨기거나 다시 표시할 수 있습니다. 아이콘을 우클릭하면 다음 기능을 사용할 수 있습니다.

- **랭킹:** 공동 랭킹과 개인 최고 점수 확인
- **버전:** 현재 버전과 업데이트 내역 확인
- **업데이트:** 새 버전 확인 및 설치
- **챌린저 배트 체험:** 현재 실행 중에만 챌린저 배트 사용
- **점수 이펙트 미리보기:** 경계 점수별 효과 확인
- **종료:** 게임 완전 종료

챌린저 배트 체험은 실제 개인 최고 점수와 랭킹을 변경하지 않으며, 체크를 해제하거나 게임을 재실행하면 원래 배트로 돌아옵니다.
